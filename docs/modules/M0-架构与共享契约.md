# M0：架构与共享契约

**边界**：建立 Next.js、TypeScript、数据库迁移与种子数据、身份占位、统一错误响应、规则引擎和共享类型；不开发业务流程页面。

**交付**：`config/business-rules.yaml`、`src/lib/rules/*`、`src/types/*`、数据库 schema/seed、`/api/health`、`docs/API-CONTRACT.md`、数据字典。

**关键约束**：模板函数、日期标签、电话和车型转换都由规则层处理；任何批次记录必须有 `ruleVersion`、`contentSnapshot`；模板不得在页面中硬编码。

**验收**：YAML 能读取和校验；错误规则明确报错；模板、电话转换单元测试通过；健康检查返回成功。
