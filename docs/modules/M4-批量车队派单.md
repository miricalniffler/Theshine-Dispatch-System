# M4：批量车队派单

**边界**：仅预览、复制、人工确认车队派单；不发送微信/WhatsApp。

**分组规则**：订单必须同一 `serviceDate`、同一城市、同一 `fleetId`，且状态为待派车；缺派单必填字段或异常订单不得进入批次。

**数据/API**：`dispatch_batches`、`dispatch_batch_orders`；`POST /api/dispatch-batches/preview`、`copy-log`、`confirm`。

**渲染规则**：对每单渲染同一份 `templates.dispatch.header + body`，按订单顺序拼接；最后读取 `templates.dispatch_batch_footers[city]`。严禁在 TS/TSX 中写曼谷、苏梅尾注。

**验收**：混日期/城市/车队均拒绝；复制不变状态；确认后保存快照与日志，并变为待司机资料；两城市尾注精确匹配 YAML。
