# M7：规则中心

**边界**：规则草稿、YAML/字段/模板校验、示例预览、发布、历史与回退；不可直接覆盖已发布版本。

**数据/API**：`rule_versions`；`GET /api/rules/current|history`、`POST /api/rules/preview|publish`、`POST /api/rules/:id/rollback`。

**页面**：左侧规则分类，中间 YAML 编辑区，右侧示例订单预览，底部版本历史。

**验收**：非法 YAML、未知变量/函数、缺关键结构不可发布并提示问题；发布仅影响后续生成；旧批次快照不改变；回退以发布新版本实现。
