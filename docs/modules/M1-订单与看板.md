# M1：订单与看板

**边界**：订单新增、编辑、查询、日期/城市/车队/状态/关键词筛选、统计、多选、状态展示、操作记录。导入解析、派单、司机资料和回传不在本模块。

**数据/API**：`orders`、`activity_logs`；`GET/POST /api/orders`、`GET/PATCH /api/orders/:id`、`GET /api/orders/:id/activity`、`GET /api/dashboard/summary`。

**页面**：`/orders` 支持今天、未来、自定义范围；`/orders/[id]` 显示状态条、订单编辑和操作记录。

**验收**：缺核心字段只能是待核对；多选不改状态；异常与临近订单置顶；编辑后写入日志。
