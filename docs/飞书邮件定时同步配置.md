# 飞书邮件每小时同步配置

系统提供一个受保护的同步入口：`GET /api/cron/feishu-mail`。它每次只接受飞书订单、变更和取消邮件，并以邮件 `id` 去重；新订单会创建，已有订单会更新，取消邮件会把订单标记为 `CANCELLED`。每次执行结果都会保存在本地数据库，可通过 `GET /api/import-sync/feishu-mail` 查看最近一次状态。

## 需要提供的真实配置

- `FEISHU_MAIL_IMPORT_ENABLED=true`
- `FEISHU_MAIL_IMPORT_URL`：你们的飞书邮件导入桥接地址（HTTPS）
- `FEISHU_MAIL_IMPORT_TOKEN`：桥接地址的访问令牌
- `FEISHU_MAIL_ALLOWED_SENDER`：允许的发件人地址；默认 `dingdan@theshine.com.cn`
- `FEISHU_MAIL_SYNC_ENABLED=true`
- `CRON_SECRET`：足够长的随机密钥

桥接地址必须返回 JSON 数组或 `{ "items": [] }`。每项至少提供邮件唯一 `id`、订单原文 `text`（也接受 `body`、`rawText`、`content`）、`subject` 与 `sender`；取消邮件可提供 `action: "cancel"`，或让主题/正文含有 `cancel`/`取消`。桥接地址负责安全地调用飞书邮件能力；本项目不保存飞书账号密码，也不会自动读取未授权邮箱。

## 每小时触发

若部署在 Vercel，仓库内的 `vercel.json` 配置为整点运行。其他环境可用任意定时器每小时调用一次：

```text
GET https://你的域名/api/cron/feishu-mail
Authorization: Bearer <CRON_SECRET>
```

没有真实桥接地址、令牌、发件人授权或定时器密钥时，同步接口会返回明确的“未配置”错误；不会将其记为同步成功。
