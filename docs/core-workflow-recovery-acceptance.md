# 核心业务恢复验收记录

日期：2026-10-16

## 已修复的阻塞点

- 订单详情读取不再等待泰文 AI 翻译；AI 只会在运营人员明确点击分析时调用。
- 订单详情与操作记录读取只使用稳定的司机资料字段。测试库尚未执行可选字段升级时，订单不会再被误显示为不存在。
- 详情页遇到网络、鉴权或服务错误时会显示原因、重试和返回入口，不会永久显示“正在读取订单”。备注和取消入口会随订单正常读取恢复可见。
- 编辑、飞书取消与 i'way 回传确认均以数据库内的当前订单状态为准，避免取消订单被后续操作覆盖。
- i'way 预览、复制和确认接口对空请求、异常服务响应返回 JSON；页面不会再把 HTML/空响应误报为 `Unexpected end of JSON input`。
- esforty 紧凑订单号支持前导 `#`、非断行空格、连字符和更多分组形式；车型支持常用缩写及 Plus 标记。
- 未配置访问口令时，站点改为拒绝访问而非意外放行。

当前本机没有隔离 PostgreSQL，也没有 Preview 测试账户或独立测试数据库凭据。本轮没有读取、修改或迁移任何远程数据库，也没有发送真实 i'way/飞书消息或调用付费 AI。

在独立 Preview 数据库创建后，管理员应先审查并显式执行现有 Prisma migration，再使用一笔可丢弃的测试订单完成：导入、搜索、编辑、备注、取消、司机资料保存、i'way 预览/复制/确认。确认前不得复制到真实业务平台。
