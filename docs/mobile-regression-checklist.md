# 手机端回归测试清单

本清单以 iPhone 16 竖屏（393 × 852）为主要验收尺寸。每次涉及导航、订单、车队回复、i’way 回传或全局样式的修改后，都应完成对应检查。

## 自动化烟雾测试

运行前准备一个**测试环境**或已授权的预览环境，并在本机设置以下变量：

```sh
PLAYWRIGHT_BASE_URL=https://你的测试地址 \\
E2E_TEAM_ACCESS_PASSWORD=团队访问密码 \\
npm run test:mobile
```

测试只会登录、打开页面、展开筛选和检查页面布局；不会点击“同步飞书”、不会上传图片、不会调用 AI、不会保存资料，也不会确认 i’way 回传。

若未提供 `E2E_TEAM_ACCESS_PASSWORD`，测试仍会检查登录页面，但会跳过登录后的页面。这能避免在电脑或持续集成环境中保存密码。

测试覆盖的设备：

| 设备类型 | 尺寸 | 用途 |
| --- | --- | --- |
| iPhone 16 | 393 × 852 | 主要验收基准 |
| 小屏 iPhone | 375 × 812 | 防止窄屏内容溢出 |
| 大屏 iPhone | 430 × 932 | 检查大屏安全区与底部操作栏 |
| Android Chrome | 412 × 915 | 检查 Android 触屏浏览器 |
| 桌面 Chrome | 1440 × 1000 | 防止手机改动破坏电脑工作台 |

自动化测试会保存失败截图和运行录像到测试结果目录，便于检查；这些文件不应提交到 Git。

## iPhone 16 手工验收

### 进入与导航

- [ ] Safari 竖屏打开网站，登录页、密码框和“进入系统”按钮均不横向溢出。
- [ ] 登录后可单手点击底部导航；“更多”能打开和关闭。
- [ ] 所有主页面可以回到订单工作台。
- [ ] 地址栏、底部 Home 指示条不会遮挡固定操作按钮。
- [ ] 横屏后内容仍可阅读；切回竖屏不会丢失已输入但未保存的文字。

### 订单工作台

- [ ] 首屏显示订单卡片，而非必须横向滚动的大表格。
- [ ] “筛选订单”可打开和收起；日期、城市、车队、状态、关键词均可操作。
- [ ] 订单号、乘客、路线较长时会换行或省略，不撑破页面。
- [ ] 订单详情、派单、录入资料、回传 i’way 入口均可点击。
- [ ] 点击“同步飞书并刷新”仅在人工确认需要时使用；同步期间按钮不会重复提交。

### 订单详情与高频动作

- [ ] 详情页或详情抽屉可完整关闭并返回列表。
- [ ] 电话使用 `tel:` 打开拨号；地址使用地图链接打开地图。
- [ ] “复制派单文本”“在 WhatsApp 打开”“复制回传内容”均可用。
- [ ] iPhone Safari 不允许自动复制时，页面会明确提示并允许长按手动复制。
- [ ] 手机键盘弹出后，保存、取消和关闭按钮仍可操作。

### 车队回传与 i’way 回传

- [ ] 默认选择明日订单，且可下拉切换其他日期。
- [ ] 文字粘贴、相册选图、拍照、图片删除和图片预览均正常。
- [ ] 不上传或不粘贴任何内容时，不会误发起 AI 请求。
- [ ] 生成 i’way 内容后可复制；“已向 i’way 回传”可返回订单工作台。
- [ ] 单笔补发和明日批量回传均保持接客时间排序。

### 安全与可安装性

- [ ] 退出登录后，返回键不会重新显示订单和乘客资料。
- [ ] 手机浏览器的离线缓存中不含订单、电话、地址、司机资料、图片或回传文本。
- [ ] 添加到主屏幕后可正常打开；弱网时只显示不含订单资料的离线提示。
- [ ] 使用另一位同事的账号登录时，不复用上一位用户的本地会话或页面数据。

## 兼容性回归

每次发布前至少在下列组合各做一次快速检查：

- iPhone 16 Safari（真机）
- Android Chrome（真机或模拟器）
- 桌面 Chrome
- 桌面 Safari（如可用）

重点确认复制、WhatsApp 跳转、拨号、地图、文件选择、粘贴图片、筛选抽屉和底部安全区。自动化测试不能替代真机检查，尤其是 iOS 的剪贴板、文件选择器和分享跳转。
