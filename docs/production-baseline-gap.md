# Production 基线功能差异

本清单只用于本分支的增量开发决策。PR #12、#13 的实现不作为合并来源。

## 当前 Production 可直接复用

- 订单导入、列表、详情页编辑、司机/车辆资料录入。
- 车队回复工作台：原文与图片保存、人工核对、写入司机资料、i'way 文本预览与复制记录。
- i'way 回传批次预览、复制、人工确认；订单资料完整性会在预览时校验。
- 飞书邮件同步、重复订单的基础识别，以及同步状态提示。
- 泰文司机姓名转写入口、车辆图片上传与 Qwen 辅助识别入口（实际调用受新开关控制）。

## 已验收但 Production 尚缺少

- 首页订单浮窗内的异常备注、软取消、取消原因展示与恢复订单。
- 取消/恢复后使旧 i'way 回传预览失效的完整保护。
- 车牌为主键的车辆历史复用、人工确认资料保护、同车多司机历史。
- 截图作为结构化来源时的 GLM 首选 / Qwen 备用、明确的识别证据和失败原因。
- 飞书同步与本地人工编辑/取消之间的冲突策略及可重试结果。
- AI 对比测试独立真实调用开关。

## 本分支正在补齐

- 已完成：首页订单浮窗编辑、异常备注、软取消、恢复和取消原因摘要；取消后的编辑拦截及 i'way 确认前重校验；飞书取消/更新冲突保护；AI 车辆与截图识别服务端开关、GLM-5.3-Flash 30 秒首选、Qwen3.7-Plus 备用；车牌历史车型复用。
- 保留待人工验收：车队截图与车辆图片的真实模型结果、泰文姓名转写准确性、飞书连接账号的真实同步行为。
- 数据库原则：先使用已有字段和审计表；只有无法安全表达业务状态时才单独评审最小 migration。
