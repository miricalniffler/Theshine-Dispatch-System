# 司机与车辆储备库迁移说明

迁移 `20261019120000_add_driver_vehicle_archives` 只新增表、索引和可空字段；不会读取、扫描、更新或删除任何既有订单、司机资料、车辆资料或回传记录。

上线前先使用现有 Supabase 逻辑备份方案保留一次可恢复备份，并在隔离数据库运行 `npx prisma migrate deploy`。验证新表存在、现有订单数量不变后，才可在 Production 执行同一命令。

若上线后需要回退应用代码：先回退应用版本即可。新表和新字段均不会被旧代码读取，因此**不要**为回退删除表或字段。保留它们即可保证新功能创建的档案和审计记录不会丢失。

本迁移没有数据回填任务。新档案只在上线后运营人员保存或更新司机车辆资料时创建。
